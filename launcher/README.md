# 실행기 (선택 사항)

가장 좋은 방법은 앱을 **설치**하는 것입니다. 앱을 열고 `설정 → 앱 설치`(또는 Chrome/Edge 주소창의 설치 아이콘)를 누르면
바탕화면·시작 메뉴에 아이콘이 생기고, **아이콘을 두 번 클릭**하면 별도 창으로 실행됩니다.

설치 기능을 쓸 수 없는 환경이라면 아래 파일을 바탕화면에 복사해 두고 더블클릭하세요.

| 파일 | 대상 | 동작 |
| --- | --- | --- |
| `TemplateKit-Windows.bat` | Windows | Edge(없으면 Chrome)를 주소창 없는 앱 창으로 실행 |
| `TemplateKit-Mac.command` | macOS | Chrome(없으면 Edge·기본 브라우저)으로 실행 |

배포 주소가 바뀌면 두 파일의 `URL=` 줄을 수정하세요.
