# PC · 모바일 동기화 설정 (Firebase)

같은 계정으로 로그인한 PC와 휴대폰이 문서와 프리미엄 등록을 실시간으로 공유하게 하는 설정입니다. 처음 한 번, 10분 정도 걸립니다.
무료 요금제(Spark)는 하루 읽기 5만 회, 쓰기 2만 회, 저장 1GB까지 무료라서 개인용과 초기 판매 단계에서는 비용이 들지 않습니다.

## 1. 프로젝트 만들기
1. <https://console.firebase.google.com> → **프로젝트 추가** → 이름 입력(예: `templatekit`) → Google 애널리틱스는 꺼도 됩니다.

## 2. 로그인 방식 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭에서 **이메일/비밀번호**를 사용 설정합니다. 원하면 **Google**도 켭니다.
3. **설정 → 승인된 도메인**에 `tlsgusdlf33.github.io`(실제 배포 주소의 도메인)를 추가합니다. `localhost`는 기본으로 들어 있습니다.

## 3. 데이터베이스 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
3. **규칙** 탭에 이 저장소의 [`firestore.rules`](../firestore.rules) 내용을 그대로 붙여넣고 **게시**합니다. 각 사용자가 자기 데이터만 읽고 쓰게 하는 규칙입니다.

## 4. 앱에 연결
1. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`) 앱 추가** → 앱 닉네임 입력 → 등록
2. 화면에 나온 `firebaseConfig` 값을 `app/js/config.js`의 `firebase:`에 붙여넣습니다.

```js
firebase: {
  apiKey: 'AIza...',
  authDomain: 'templatekit-xxxx.firebaseapp.com',
  projectId: 'templatekit-xxxx',
  storageBucket: 'templatekit-xxxx.appspot.com',
  messagingSenderId: '...',
  appId: '1:...:web:...',
},
```

3. `npm run bump -- minor "PC·모바일 동기화 지원"` 후 커밋하고 push합니다. 설치된 앱들도 업데이터로 받습니다.

> `apiKey`는 비밀번호가 아니라 프로젝트를 가리키는 식별자라서 공개 저장소에 올려도 됩니다. 실제 보호는 3단계의 보안 규칙이 합니다.

## 동작 방식
- 데이터 위치: `users/{사용자ID}/docs/{문서ID}`(문서), `users/{사용자ID}`(라이선스 코드 목록)
- 로그인 전에 만든 문서는 처음 로그인할 때 그 계정으로 올라갑니다.
- 다른 계정으로 쓰던 기기에서 로그인하면, 두 계정의 데이터가 섞이지 않도록 그 기기의 문서를 비우고 새 계정의 문서를 받아옵니다.
- 오프라인에서 고친 내용은 기기에 저장되어 있다가 연결되면 올라갑니다. 같은 문서를 두 기기에서 동시에 고치면 **마지막에 저장한 쪽**이 남습니다.
- 삭제는 다른 기기에도 전달됩니다.

## 문제 해결
| 증상 | 해결 |
| --- | --- |
| `auth/unauthorized-domain` | 2-3단계의 승인된 도메인에 배포 주소를 추가합니다. |
| `auth/operation-not-allowed` | 2-2단계에서 해당 로그인 방법을 사용 설정합니다. |
| “서버 접근 권한이 없습니다” | 3-3단계의 보안 규칙을 게시했는지 확인합니다. |
| 배지가 계속 “동기화 중…” | 인터넷 연결을 확인합니다. 연결되면 자동으로 다시 시도합니다. |
